# 水之天堂 · 庭院工坊

第三阶段的本地浏览器版本。用堆叠方块搭建多层庭院，以水的连通性、推拉、浮船和落水水花解谜。

## 打开

当前开发地址：[http://127.0.0.1:4180/](http://127.0.0.1:4180/)。点击右上角「试玩庭院」；「返回编辑」恢复原草稿。

重新启动：

```powershell
cd 'E:\content\_200_study\_230_programming\_238_codex\水之天堂'
npm run dev -- --port 4180 --strictPort
```

首次安装用 `npm ci`。本机已安装依赖，Node.js 22.19.0。使用支持 WebGL 2 的 Chrome / Edge；通过本地服务打开，不直接双击 HTML。

## 操作

| 编辑器 | 操作 |
| --- | --- |
| 放置 / 连续笔刷 | 左键单击 / 拖动 |
| 删除 / 连续擦除 | 右键单击 / 拖动 |
| 取样类型与方向 | 中键点按 |
| 环绕 / 缩放 | 中键拖动 / 滚轮 |
| 方向 / 笔刷大小 / 聚焦 | R / [ 与 ] / F |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y |
| 保存 | Ctrl+S；同时支持自动保存 |

命中实体按命中面相邻放置，指向虚空才使用「放置层」。没有升高或设置高度工具；高度通过实体堆叠形成。地图宽、深为 4–32 格，竖直 32 层。

| 试玩 | 操作 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 不耗回合转向 | Shift + 移动方向 |
| 远程拉取 | X |
| 等待 | 空格 |
| 撤销 / 重做 / 重开 | Z / Y / R |
| 返回编辑 | Esc 或右上按钮 |

WASD 与方向键相对当前视角：W 朝画面前方最接近的格子方向。按住可以连续行走，转动相机只影响下一步。Shift＋方向键采用相同映射，画面底部显示当前 W/A/S/D 对应的世界方向。「动作」可选完整、简化、跟随系统，默认完整；「暂停水面」只停持续流纹，不停位移与涨落。

胜利条件：全图恰好一条实际出水边，主角到达它所属的格子与水层。楼上不会触发楼下出口。水不会随着等待累积；动画与规则分开运行。

## 内容

- 原四个水流示例、六个新机制实验、两个带验证路线的综合关卡，共 12 关。
- 章节管理、堆叠编辑、三种方形笔刷、矩形铺设、剖视与物件取样。
- IndexedDB 自动保存；单关及整套 JSON 导入导出；删除后可恢复。
- 木块、拉环箱子、玻璃、铁架、薄船板与首块绑定载荷；后续方块独立堆叠，可整组推动、拉取或被水花驱动。
- 原创程序化紫色小石像鬼、走步/推拉/攀爬/下落/吐水、实体链条与水体动效。
- [第一阶段美术样板](http://127.0.0.1:4180/showcase.html)。

## 检查和构建

| 命令 | 用途 |
| --- | --- |
| `npm run typecheck` | 严格类型检查 |
| `npm test` | 独立于浏览器的规则与编辑器测试 |
| `npm run build` | 检查并生成生产文件 |
| `npm run preview` | 生产预览，默认 4173 端口 |
| `npm run test:browser` | Chrome 开发页面与 Edge 生产预览测试；先构建 |
| `node scripts/export-levels.mjs` | 导出机制关卡、验证路线并记录求解性能 |

浏览器测试使用本机 Chrome 和 Edge，自动启动 5173 / 4173 两个验收服务。4180 为当前可试玩地址。4175 目前由另一个目录的服务占用，本工程不会关闭或修改它；跨端口资料迁移的限制见下文。
