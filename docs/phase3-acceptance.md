# 第三阶段验收记录

2026-09-24，本地浏览器版本。正式入口为 `http://127.0.0.1:4180/`，美术样板为 `/showcase.html`。

## 交付

完成三维堆叠编辑器、章节与关卡管理、IndexedDB 自动保存、JSON 导入导出、独立试玩副本、三维水流与物件规则、紫色小石像鬼及动作表现。第一阶段美术样板仍可打开。十二个内置关卡包含四个水流基础、六个物件实验和两个附有世界方向验证路线的综合关卡，导出文件在 `levels/phase3/`。

## 验证

- `npm run build` 通过类型检查并生成生产文件。
- `npm run test:core`：61 项通过，包括旧版水流回归、堆叠、桥下水、玻璃、船、重力、推拉、载荷转换、撤销与重做。
- `npm run test:browser`：Chrome 开发页与 Edge 生产预览共 46 项通过。覆盖创建章节、堆叠、矩形、笔刷、取样、删除、试玩、返回编辑、路线通关、导入失败保护、V1 草稿迁移、两种桌面尺寸与最大地图。
- 操作、动画、玻璃与跨端口资料的专项记录见 [修订验收](revision-acceptance.md)。

## 性能记录

32×32×32 层实心地图共 32768 个物件。Node 核心求解基准中位数约 12.6 ms；Chrome 生产场景构建约 125 ms、Edge 约 115 ms。浏览器自动化的无显示器帧率约 185–200 FPS，属于未受显示器刷新率限制的测试值，不能代替用户设备上的实测帧率。详细样本见 `docs/phase3-core-performance.json` 与 `docs/phase3-*-volume-performance.json`。

当前本机 4175 是另一目录的服务，未改动。4180 无法直接读取该服务所属地址的浏览器资料；页面提供 JSON 导入提示，细节见 [迁移说明](phase3-migration.md)。
