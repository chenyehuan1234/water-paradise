# 操作、动画与浮船修订验收

2026-09-24，开发页 Chrome、生产预览 Edge；1920×1080 和 1366×768。4180 开发入口持续运行。

## 实际行为

| 项目 | 验证结果 |
| --- | --- |
| 动作与历史 | 走步、推、拉、攀爬、下落、撤销、重做均有中间帧；动画中撤销从当前显示位置回退，涨水与撤销后的降水都测到中间高度，瀑布高度同步过渡。8 段 WebM 留档。 |
| 连续操作 | 独立按住检测，不依赖键盘自动重复；按住可连走，快速换向衔接下一步，松键、碰墙、失焦、重开和撤销停止追加。 |
| 随视角移动 | 四个侧视和顶视检查 W 的世界方向；Shift＋方向与移动共用映射，每步开始锁定方向。 |
| 玻璃编辑 | 顶面四边自动吸附；手动四向、侧缘延长、上沿叠高、竖直矩形、一笔撤销、中键取样与右键删除通过鼠标操作测试。 |
| 浮船 | 一格深水中承载面在水面；薄板约 0.2 格，首块保持完整一格并绑定，第二块独立。上层箱子可单独拉走，船与首块不挡水，整摞净空限制有效。 |
| 数据迁移 | 隔离浏览器中模拟旧址迁移页，空库保留 ID、已有内容以副本合并、旧多载荷转换、刷新恢复和旧库不变均通过。 |

## 检查与限制

类型检查、生产构建、61 项核心测试、46 项双浏览器回归均通过。随后新增的碰墙、失焦、快速换向和降水专项测试又在 Chrome、Edge 分别通过。迁移专项验证结果在 `docs/revision-migration-check.json`。性能样本见 [第三阶段验收](phase3-acceptance.md)。

当前实际 4175 服务不属于本工程，缺少只读迁移页。本工程先探测专用标记，探测失败不会加载那个页面或改写旧库；4180 明示需从旧页导出 JSON 再导入。自动迁移的空库与合并流程通过隔离环境验证，尚未对实际占用 4175 的另一工程执行资料搬迁。
