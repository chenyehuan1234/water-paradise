## 六个新机制实验

| 关卡 | 操作与观察 |
| --- | --- |
| 整列与堆叠 | 从初始位置按 W，整列箱子和上方木块同步向北移动 |
| 桥下的水路 | 观察悬空结构下的水层；切换玻璃类型比较阻水；桥板仍透水 |
| 台阶与铁架 | W/W 走上台阶，再 D 进入同高铁架；不能从低处直接爬铁架 |
| 浮船与永久载荷 | 箱子和木块分别成为各自船的首块绑定载荷；完整一格，船和绑定块不挡水 |
| 隔水牵引 | Shift+D 面朝东，再 X，两船各相向一格；相邻后再拉会整体拒绝 |
| 落水的力量 | D 将高处木块推入原有深水，相邻船沿东侧滑至障碍前停下 |

## 两个综合验证关卡

### 庭院归途 · 推

起点 `(5,1,1)`，箱子在 `(5,1,2)`。上方增加了桥板、悬空结构和玻璃，保留下层水路。

路线：**S → A → S → A → A → A → A**。

第一步把箱子推到 `(5,1,3)`，右支流变干，只剩 `(0,1,3)` 的西侧出口。第七回合主角抵达该格并通关。

### 庭院归途 · 拉

起点 `(5,1,4)`，箱子在 `(5,1,2)`。

路线：**Shift+W → X → A → W → A → A → A → A**。

转向不消耗回合。X 将箱子拉到 `(5,1,3)`，封住右侧水路；主角经 `(4,1,4)` 绕回主水道，第七回合抵达西侧唯一出口。

两条路线已在纯规则测试、Chrome 开发页和 Edge 生产预览中执行。路线以 `route` 命令数组随 JSON 保存，可复核。这里只验证这些路线能够通关，不声称关卡只有一种解法。

三章十二关由本工程提供，兼作水流、物件、编辑和动画验收内容；后续仍可在编辑器中扩写或调整。

上述 WASD 字母是默认相机视角下的操作提示；JSON `route` 保存的是世界方向，不受旋转相机影响。转动相机后请以画面底部的方向提示为准。
