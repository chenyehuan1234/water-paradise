# 美术规范 · 01 空中庭院

## 已确定的方向

从用户参考图提炼“悬空庭院、暖色石材、青蓝水体、少量植物、透明边界”，简化为柔和、清晰的三维微缩景观。水是画面中心，建筑为水路提供轮廓，植物只在边角形成节奏。

第一阶段的实际场景是后续制作的可运行风格样板；照片里的砖纹、复杂花饰、家具和角色没有照搬。

## 色彩

下表是材质底色，不等于受灯光与色调映射影响后的截图像素色。统一定义在 `src/scene/config.ts`。

| 用途 | 色值 | 约定 |
| --- | --- | --- |
| 主体石材 | `#D9C49E` | 暖砂色，主要用于墙面与基础 |
| 浅色石面 | `#EAD9B9` | 地砖、拱门与支撑 |
| 陶粉顶面 | `#E4BAA7` | 上层砖面、台阶和少量压顶 |
| 奶油白 | `#F4E5CC` | 池边、薄檐与小面积高光 |
| 水体主色 | `#369FAA` | 青蓝色，区别于植物和石材 |
| 水体浅色 | `#A0D8CC` | 水面轻微色差与流动层次 |
| 泡沫 | `#F1F8E9` | 低面积岸线、瀑布和涟漪 |
| 植物 | `#9EB76A / #C0CF85 / #6E9867` | 成簇分布，避免逐片写实叶脉 |
| 金属 | `#8B946E` | 柔和灰绿金属，细窄栏杆 |
| 背景 | `#DCE5DB` | 灰绿中心，四周轻微收暗 |

建筑占最大面积，水体是第二视觉层级；植物和陶粉提供少量点缀。互动界面仅使用深绿色强调色。

## 几何与材质

- 1 格 = 1 个场景单位，样板占地约 8×8 格；地砖宽 0.97，留出缝隙来表达格子，不使用满屏黑色描边。
- 主要石块倒角约 0.055，细薄地砖倒角约 0.035；同一类模块共享几何体和材质。
- 墙体使用大块分缝，避免密集砖纹。台阶顶面用陶粉，立面用主体石色，高低差同时通过轮廓与阴影表达。
- 石材粗糙度 0.85、金属度 0；陶瓷池底略光滑；植物以低细分椭球组合，保持可读剪影。
- 护栏采用单层透明面、0.15 不透明度、关闭深度写入；金属边框单独建模。不使用多层厚玻璃折射。
- 庭院背面同样有完整实体，允许自由观察，不依赖单张正面图片。

## 水体与光照

- 水面为水平薄面，以程序化波纹、低强度高光、池边不规则白色泡沫表现流动；使用统一时间驱动。
- 瀑布使用双面透明薄面，以竖向细纹和向下滚动的明暗表现落水，底部四道淡涟漪循环扩散。
- 水面透明度接近 0.9，以稳定的色块和水路辨识度为先。上层水池与水槽接合处留出泡沫缺口。
- 暖色方向光位于左上方，配合中性偏绿的半球光和低强度冷色补光。采用柔化 PCF 阴影、ACES 色调映射和 sRGB 输出。
- 悬空感由薄基础、背景留白和下方柔和阴影表达。轻微环境雾只统一远近色调；不使用强景深、强 Bloom 或镜头炫光。
- 本阶段水面不参与真实光学反射、流体物理或游戏求解，表现参数不能用于推断玩法规则。

## 构图与界面

- 正交相机保持微缩模型感；初始方位角 36°、俯视角 33°，围绕庭院中心旋转。
- 整屏优先展示庭院，左上为标题，右上为章节标记，底部为短说明和三个控制按钮。小窗口隐藏次要说明，不覆盖主要场景。
- 标题用本地宋体系列，正文与控制采用本地中文无衬线字体，不依赖外部字体请求。
- 文本使用深绿色；控制区域采用浅色底，44px 最小按钮高度、明确焦点和状态文本。网格状态不只靠颜色表达。
- 动效可暂停，系统减少动态效果时默认静止；保持场景可观察和按钮可操作。

## 后续资产遵循

角色和物品将与本阶段风格统一，但造型与功能在第三阶段确定。第二阶段先保证水路、阻挡和高低差的信息清楚，再决定新增水体状态的视觉编码，不提前把装饰当作可互动机关。
