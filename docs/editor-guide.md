# 庭院工坊使用说明（第三阶段）

## 从空白庭院开始

1. 左侧「＋」创建章节，在章节内点击「新建关卡」。默认地图 12×12，初始为空白。
2. 右侧选择庭院石块，在中间画布点按或拖动。第一次在放置层 0 放置，之后点石块顶面逐块堆高，点侧面可横向延伸。
3. 使用 3×3 / 5×5 笔刷快速铺设；或勾选矩形，按下左键后拖动到对角并松开。矩形始终保持在起笔平面。
4. 铁架按水平面放置；下方留出至少一格可供角色通行。角色只能从同高处进入铁架。玻璃默认自动吸附：指向方块顶面靠近哪条边，就放到对应边。右侧可选「北／东／南／西」进入手动方向，点「自动吸边」恢复；R 会旋转并切到手动模式。
5. 放置箱子、水源和出生点。「角色与水源」在右侧物件库下方，可独立滚动找到。
6. 点击「试玩庭院」。物件先落稳，再开始计回合。返回编辑会恢复建造时的布局，不带回试玩位置、载荷或回合。

## 精确建造

- **左键建造、右键删除、中键观察**。中键位移不足 5 个屏幕像素为取样；达到阈值才开始旋转。旋转结束不会取样。
- **命中优先**：命中实体就在命中面旁放置，无论放置层是多少。只有没有命中时，鼠标射线才与放置层相交。
- 已有玻璃的上沿可叠高，左右边缘可延长；玻璃笔刷与矩形固定在所选竖直边界平面。右键的拾取范围比视觉薄片宽，便于删除玻璃而不误删后方石块。
- 实体已有占位会显示红色预览，不覆盖物件。绿色情况可放置。右键显示删除高亮。
- 单次笔画使用起笔时的物件快照。新增物件不变成同一笔的垒高目标；删掉前排后不会在同一笔继续擦穿后排。
- 一次完整拖动仅占一次撤销。矩形结束才提交；按 Esc 可以取消尚未提交的笔画。
- R 顺时针转向；[ / ] 依次选 1、3、5 格笔刷；F 聚焦悬停位置。按钮同样可操作。
- 顶视和四个侧视方便对齐；重置返回斜俯视。滚轮缩放，中键 360° 环绕。
- 「剖视：显示到层」按物件基底高度隐藏上方物件。隐藏的物件不能被鼠标命中，仍参与占位与水流计算。降低剖视值不会删除物件。
- 无支撑的动态物件允许保存在草稿中，会显示提示。编辑时不重力坠落；试玩初始化统一落稳。

## 检查水路

黄点标记的是实际流向虚空的边；同格两条边分别计数。内部落水不计为出口。检查面板显示悬停坐标、物件、水类型、水深与该层出口。

青蓝薄水为平流层，水面高于承接面则为深水。勾选「水深」使用更强的深浅配色。水源从天空落到这一列最高的承接实体；即使在下层设置其坐标，也不会穿透上方实体。

编辑后立即重新求解。箱子堵缺口可升水；支流失联立即消水。船与合并载荷始终不挡水，铁架透水，两种玻璃都挡角色但只有实心玻璃挡水。

## 管理关卡

左侧展开/收起章节。章节旁的菜单支持重命名、复制、排序和删除。左下方可以对当前关卡重命名、复制、排序、跨章节移动及改地图尺寸。删除进入回收站，可恢复整章或单关。

缩小尺寸不能裁掉范围外物件或标记；需要先处理这些物件。角色与水源可以暂缺，草稿仍可保存；进入试玩时才检查完整性。结构检查不保证谜题有解。

## 保存与交换

草稿、章节和每关编辑设置保存在当前浏览器当前地址的 IndexedDB。右上角显示保存结果。Chrome / Edge、不同端口和不同浏览器资料是不同存储空间。4180 会检查 4175 是否提供本工程的迁移页；当前本机 4175 是另一工程，需在旧页导出 JSON，再在新页导入。

「导出本关」生成单关 JSON，「整套导出」包含章节、关卡与工程数据。「导入」先校验完整文件，再加入新副本；即使 ID 相同也不覆盖原关卡。文件无效时原草稿保持不变。

保存失败时本页仍可继续编辑与导出；请在关闭页面前导出。回收站也随工程保存。旧 V1 草稿会迁移并保留原数据与 IndexedDB 备份，详见迁移文档。

## 试玩

WASD / 方向键相对当前相机移动，W 指向最接近画面前方的世界格子方向，画面底部实时显示映射。每步起动时锁定方向，旋转相机影响下一步；按住方向键连续走动，松键停止追加。Shift + 方向原地转向也相对当前视角，X 拉箱，空格等待。优先推动，确实不能推动才尝试爬一格；挡水石柱、玻璃和高处铁架不允许这样攀爬。可以向下落多格，但不能主动踏入无底虚空。

水完全不阻挡或托起主角；船可承载角色。船是约 0.2 格厚的薄板，一格深水就能浮到水面。第一块箱子或木块与船绑定并保持一整格，后续方块为可拆走的独立堆叠；主角站在当前最上方。绑定箱子的船可牵引，上层独立箱子只拉箱子本身与其普通堆叠。船在深水中不能手推。

Z / Y 撤销重做，R 重开。试玩撤销、重做也沿动作路径播放，动画中撤销从当前显示位置回退；重开立即中止动画。编辑器撤销有短淡入淡出。画面下方「动作」默认完整，也可选简化或跟随系统；选择跟随系统时才按系统减少动态效果直接切换。「暂停水面」只暂停持续流纹，不停止规则或水位涨落。
